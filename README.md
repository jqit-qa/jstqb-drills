# JSTQB FL 第1章・第2章 確認ドリル

JSTQB Foundation Level（CTFL v4.0）第1章・第2章を対象とした、新人向け4択ドリルです。

## 公開ファイル

- `index.html`：GitHub Pagesで公開する本番ドリル
- `JSTQB_FL_1-2章_確認ドリル.html`：旧URLからルートURLへ転送する互換ページ
- `JSTQB_FL_1-2章_4択問題バンク.md`：全50問と解答・解説のマスター

## 学習フロー

1. 公式シラバスの第1章・第2章を読む。
2. 全50問をシラバスのページ・節番号順で実施する。各問題のヒントから該当ページを参照してよい。
3. 初回の50問完了時に、リーダー宛へSlack通知を送る。
4. 誤答した問題だけをやり直す。
5. 全50問正解になるまで繰り返す。

開始時、選択時、問題移動時、結果画面到達時に、受講者名・現在位置・回答済み内容・習得済み問題・前回の誤答・実施回数をブラウザの `localStorage` に保存します。同じ端末・ブラウザであれば、ページを更新・閉じた後も回答途中の問題または前回の誤答から再開できます。複数端末間では同期しません。

Safari／Chromeなどの標準ブラウザで利用してください。Slackやメールなどのアプリ内ブラウザは標準ブラウザと保存領域が異なる場合があり、途中離脱後に進捗を再開できない可能性があります。モバイルではプルリフレッシュと操作対象のダブルタップズームを抑制し、44px以上のナビゲーション操作領域とiPhoneのセーフエリア余白を確保しています。ピンチズームは無効化していません。

## 問題を更新するときのルール

準拠シラバスは `JSTQB Foundation Level Version 2023V4.0.J02` です。

シラバス改訂時は、問題文、正答、節番号、ページ番号、解説を再確認してください。問題を変更するときは、問題バンクMarkdown、本番HTML内の `QUESTIONS` 配列、`SYLLABUS_PAGES` を必ず同時に更新します。

正答位置は固定表示でも推測されにくいよう、A〜Dを各12〜13問に保ちます。問題IDや保存対象の構成を変更して既存進捗と互換性がなくなる場合は、HTMLの `STORAGE_VERSION` と `STORAGE_KEY` を更新してください。

## Slack通知

公開HTMLにSlack Incoming Webhookの秘密URLを直接記載しないでください。本番HTMLの `SLACK_NOTIFY_URL` には、Slack認証情報を安全に保持するGAS WebアプリのURLを指定します。

GASのソースと運用手順は `gas/` に保存しています。Slack Incoming Webhook URLは、GASのスクリプト プロパティ `SLACK_WEBHOOK_URL` にだけ登録します。

`SLACK_NOTIFY_URL` の中継URL自体は公開HTMLから閲覧できるため、秘密情報として扱えません。また、完了通知はブラウザが生成する自己申告データであり、解答内容をサーバー側で検証していません。Slack通知にもこの注意を表示し、合格認定・人事評価などの唯一の根拠には使用しないでください。

現在のGAS中継は、要求サイズ・項目・点数・受験IDの検証、受講者名の不可視文字除去とプレーンテキスト化、同一受験IDの重複抑止、5分間10件・1日100件の投稿上限、拒否ログを実装しています。GAS WebアプリのイベントにはHTTPのOrigin/Refererヘッダーが提供されないため、この構成では信頼できる送信元検証はできません。送信元検証やサーバー発行署名が必要になった場合は、ヘッダーを参照できる中継基盤とサーバー側の受験セッションへ移行してください。

## GitHub Pages

`main` ブランチの `/(root)` を公開元に設定します。Jekyllによる変換は使用しません。

公開URLは `https://jqit-qa.github.io/jstqb-drills/` です。日本語ファイル名を含む旧URLへアクセスした場合も、このルートURLへ転送します。

## 検証

Node.jsが利用できる環境で、次を実行します。

```bash
node tests/validate-drill.mjs
```

50問構成、正答位置の分布、HTMLと問題バンク・解答表の整合、回答途中と結果画面の保存・復元・削除、旧保存形式からの移行、受講者名変更時の制御、Slack通知の重複抑止を確認します。
